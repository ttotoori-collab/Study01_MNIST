# 손글씨 숫자 인식기 (MNIST + PyTorch)

마우스로 숫자를 그리면 CNN이 0~9 중 무엇인지 알아맞히는 프로그램입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `model.py` | CNN 모델 구조 정의 (학습/추론 공용) |
| `train.py` | MNIST 데이터로 학습하고 `mnist_cnn.pt` 저장 |
| `app.py` | 마우스로 숫자를 그려서 인식하는 tkinter 앱 |
| `make_icon.py` | 앱 아이콘 `app.ico` 를 만드는 스크립트 |
| `app.ico` | 바로가기에 쓰이는 앱 아이콘 |
| `mnist_cnn.pt` | 학습이 끝나면 생기는 가중치 파일 |
| `data/` | MNIST 데이터가 자동으로 내려받아지는 폴더 |

## 사용 방법

1. 필요한 패키지 설치

```bash
pip install torch torchvision pillow numpy
```

2. 모델 학습 (가중치 `mnist_cnn.pt` 생성)

```bash
python train.py --epochs 5
```

3. 손글씨 앱 실행

바탕 화면의 **`손글씨 숫자 인식기`** 바로가기를 더블클릭하면 검은 콘솔 창 없이
앱 창만 바로 뜹니다. (`pythonw.exe` 로 실행되기 때문입니다.)

다른 실행 방법도 있습니다.

- 탐색기에서 `app.py` 더블클릭 — 콘솔 창이 함께 뜹니다(오류 확인용)
- 터미널에서 `python app.py`

## 바탕 화면 바로가기 / 작업 표시줄 고정

바로가기는 아래와 같이 설정되어 있습니다.

| 항목 | 값 |
| --- | --- |
| 위치 | `바탕 화면\손글씨 숫자 인식기.lnk` |
| 대상 | `pythonw.exe "...pp.py"` (콘솔 창 없음) |
| 시작 위치 | 프로젝트 폴더 |
| 아이콘 | `app.ico` |
| 앱 ID | `MNIST.HandwritingRecognizer.1` |

**작업 표시줄에 고정하려면** 바로가기를 마우스 오른쪽 버튼으로 클릭한 뒤
`작업 표시줄에 고정` 을 선택하거나, 바로가기를 작업 표시줄로 끌어다 놓으면 됩니다.
(윈도우 10부터는 프로그램이 자동으로 고정하는 것을 막아 두어서 이 단계만 직접 해 주셔야 합니다.)

앱 ID를 지정해 두었기 때문에, 고정된 아이콘과 실행 중인 창이 작업 표시줄에서
하나로 묶여 표시됩니다.

> 아이콘을 바꾸고 싶으면 `make_icon.py` 의 글자나 색을 고친 뒤 다시 실행하세요.
> 프로젝트 폴더를 옮기면 바로가기의 `대상`/`시작 위치` 경로를 함께 고쳐 주어야 합니다.

왼쪽 흰 칸에 마우스로 숫자를 그리면, 획을 뗄 때마다 오른쪽에
예측 숫자와 0~9 각각의 확률이 표시됩니다. `지우기` 버튼으로 다시 그릴 수 있습니다.

## 모델 구조

```
입력 (1, 28, 28)
 -> Conv2d(1, 32, 3) + ReLU      (32, 26, 26)
 -> Conv2d(32, 64, 3) + ReLU     (64, 24, 24)
 -> MaxPool2d(2)                 (64, 12, 12)
 -> Dropout(0.25) -> Flatten     (9216,)
 -> Linear(9216, 128) + ReLU
 -> Dropout(0.5)
 -> Linear(128, 10) -> LogSoftmax
```

## 참고

- 사람이 그린 글씨는 MNIST와 모양이 달라 오인식될 수 있으므로,
  `app.py`는 획을 20x20 크기로 맞추고 무게중심을 중앙에 옮기는
  MNIST와 동일한 전처리를 거친 뒤 모델에 넣습니다.
- 숫자는 칸 가운데에 너무 작지 않게, 또렷하게 써 주세요.
